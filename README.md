# Snake Water Gun Game # Snake Water Gun Game  <br>

A simple Snake Water Gun game built using HTML, CSS, and JavaScript. <br>

## 🎮 About the Game <br>

Snake Water Gun is similar to Rock Paper Scissors: <br>

- Snake drinks Water → Snake wins<br>
- Water drowns Gun → Water wins<br>
- Gun kills Snake → Gun wins<br>

The game allows the user to play against the computer with random choices.<br>

## 🚀 Technologies Used<br>

- HTML<br>
- CSS<br>
- JavaScript<br>

## ✨ Features<br>

- User vs Computer gameplay<br>
- Random computer choices<br>
- Score display<br>
- Simple and responsive UI<br>
